After it downloads — 3 quick steps

1
Unzip it.

Double-click the downloaded file to get the andx-trading-bot-main folder.

2
Open the launcher (one-time security step).

Your Mac blocks downloaded programs the first time — that's normal. Right-click Start Bot.command → Open → Open in the popup.

If you instead see “Apple could not verify…” with only Done / Move to Trash: click Done, then open menu → System Settings → Privacy & Security, scroll down, and click “Open Anyway.” You only do this once.

Double-click Start Bot (Windows).bat. If Windows shows a blue “Windows protected your PC” box, click More info → Run anyway. If it says Python is missing, install it from python.org (tick “Add Python to PATH”) and run it again.

Mac: right-click Start Bot.command → Open → Open. Windows: double-click Start Bot (Windows).bat → More info → Run anyway.

3
The dashboard opens by itself.

Your browser opens the bot at 127.0.0.1:8300. Press Start bot — it runs on practice money right away.

Safe by default. It starts in paper mode — simulated money, real prices, no account needed. Add your own ANDX keys later, only when you choose to trade live.

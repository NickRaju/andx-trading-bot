✅ No-warning install (recommended)

On a Mac: open Terminal (⌘+Space, type Terminal, Enter), paste this, press Enter:

curl -fsSL https://raw.githubusercontent.com/andxtrading/andx-trading-bot/main/install.sh | bash

On Windows: open PowerShell (click Start, type PowerShell, Enter), paste this, press Enter:

irm https://raw.githubusercontent.com/andxtrading/andx-trading-bot/main/install.ps1 | iex

Both download, set up, and open the bot with no security prompt. If Python isn't installed, it tells you where to get it. (Windows: use PowerShell, not Command Prompt.)

Or download & double-click (Windows, or if you prefer)

1

Double-click the downloaded file to get the andx-trading-bot-main folder.

2

If you instead see “Apple could not verify…” with only Done / Move to Trash: click Done, then open menu → System Settings → Privacy & Security, scroll down, and click “Open Anyway.” You only do this once.

Double-click Start Bot (Windows).bat. If Windows shows a blue “Windows protected your PC” box, click More info → Run anyway — this is normal and safe. If it says Python is missing, install it from python.org (tick “Add Python to PATH”) and run it again.

Mac: right-click Start Bot.command → Open → Open. Windows: double-click Start Bot (Windows).bat → More info → Run anyway.
